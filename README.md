# Pong Game 🎮

A simple 2-player Pong game built using Python’s built-in turtle graphics module.

## Features
- [Two-player gameplay]
- [Smooth paddle controls]
- [Ball collision detection]
- [Score tracking system]
- [Increasing ball speed after paddle hits]

  
## Technologies Used
- [Python 3]
- [turtle module]
- [time module]

  
## Controls
Player	            Move Up	           Move Down
Left Paddle	           w	                S
Right Paddle	      ↑ Arrow	           ↓ Arrow


## How to Run
- [Make sure Python is installed on your system.]
- [Save the code as main.py]
- [Run the program:]

  
## python main.py

## Game Rules
If the ball hits the top or bottom wall, it bounces back.
If the ball hits a paddle, it changes direction.
Missing the ball gives the opponent a point.
The game continues until the window is closed.
